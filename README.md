# Student Record Management System

## Project Description

The Student Record Management System is a Python-based application designed to manage student information efficiently using file handling.

It performs CRUD (Create, Read, Update, Delete) operations and stores student records in CSV or JSON format.

## Features

- Add new student records.
- View all student records.
- Update existing student details.
- Delete student records.
- Store data permanently using CSV/JSON files.
- Simple menu-driven interface.

## Technologies Used

- **Programming Language:** Python
- **Data Storage:** CSV / JSON
- **Concepts:** Functions, Lists, Dictionaries, Loops, Conditional Statements, File Handling.

## CRUD Operations

1. **Create:** Add a new student.
2. **Read:** Display student records.
3. **Update:** Modify student information.
4. **Delete:** Remove a student record.

## Student Details

- Student ID
- Name
- Age
- Course

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/your-username/student-record-management-system.git
   ```
2. Open the project folder:
   ```
   cd student-record-management-system
   ```
3. Run the Python file:
   ```
   python main.py
   ```

## Expected Output

A menu-driven application that allows users to manage student records through CRUD operations.
